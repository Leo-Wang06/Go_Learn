# 附录 D：练习与验收标准汇总

> **用途**：把 19 章的练习、必须掌握项和自测方法集中到一处，方便按阶段复习与验收。
> **使用规则**：练习题至少完成 80%；验收清单全部打勾；能用自己的话解释核心概念。
> **配套文件**：每节列出的章节目录下的 `.md` 文件。

## D.2 怎么用这份清单

1. **按章验收**：每章学完，先做练习，再逐条确认「必须掌握」。
2. **自测而不是重读**：合上书，用空白文件写出示例；写不出就是没掌握。
3. **记录卡点**：把没通过的项目写下来，回到对应章节的小节，而不是从头重看。
4. **不赶进度**：某一章验收未通过，不进入下一章；后面的内容依赖前面的类型与接口知识。
5. **最终标准**：打开 Gin/GORM 文档任意一页，能独立读懂并写出可运行示例。

> 说明：第 01–03 章讲义在 README 大纲基础上扩充了练习题（章末分为基础/进阶/读文档），本表按 README 的题目数量统计；实际练习以各章末清单为准。
