## 12.1 fmt

### 12.1.1 `Print`、`Println`、`Printf`

```go
fmt.Print("a", "b")             // ab（操作数之间不加空格）
fmt.Println("a", "b")           // a b（自动加空格和换行）
fmt.Printf("%s-%s\n", "a", "b") // a-b
```

`Print` 不加换行；`Println` 操作数之间加空格、末尾加换行；`Printf` 按格式字符串输出。日常调试用 `Println`，控制格式用 `Printf`。

### 12.1.2 `Sprintf` 与 `Errorf`

```go
s := fmt.Sprintf("用户 %d 的积分是 %d", 42, 100)
fmt.Println(s) // 用户 42 的积分是 100

err := fmt.Errorf("查询用户 %d 失败", 42)
fmt.Println(err) // 查询用户 42 失败
```

`Sprintf` 返回字符串，不直接输出；`Errorf` 返回 `error`，并支持 `%w` 包装（12.1.6）。

### 12.1.3 常用动词

| 动词 | 用途 | 示例输出 |
|------|------|----------|
| `%v` | 默认格式 | `42` |
| `%+v` | 结构体带字段名 | `{ID:1 Name:张三}` |
| `%#v` | Go 语法表示 | `main.User{ID:1, Name:"张三"}` |
| `%T` | 类型 | `main.User` |
| `%d` | 十进制整数 | `42` |
| `%s` | 字符串 | `go` |
| `%q` | 带引号的字符串 | `"go"` |
| `%w` | 包装 error | 只能用于 `Errorf` |

另外常见：`%t` 布尔、`%c` 字符、`%x` 十六进制、`%f` 浮点、`%p` 指针地址。

### 12.1.4 `%v`、`%+v`、`%#v`、`%T`

```go
type User struct {
    ID   int
    Name string
    Tags []string
}

u := User{1, "张三", []string{"go", "web"}}

fmt.Printf("%v\n", u)
fmt.Printf("%+v\n", u)
fmt.Printf("%#v\n", u)
fmt.Printf("%T\n", u)
```

输出：

```
{1 张三 [go web]}
{ID:1 Name:张三 Tags:[go web]}
main.User{ID:1, Name:"张三", Tags:[]string{"go", "web"}}
main.User
```

`%v` 快速看值；`%+v` 看字段名，调试最常用；`%#v` 看完整类型和字面量；`%T` 确认动态类型，尤其是 `any`、接口、JSON 解码结果。

### 12.1.5 宽度、精度与对齐

```go
fmt.Printf("%05d|%.2f|%8s|%-8s|\n", 42, 3.14159, "go", "go")
// 00042|3.14|      go|go      |
```

`%05d` 宽度 5、左边补 0；`%.2f` 保留 2 位小数；`%8s` 右对齐；`%-8s` 左对齐。

### 12.1.6 `%w`：包装错误

```go
base := errors.New("db down")
wrapped := fmt.Errorf("query user: %w", base)

fmt.Println(wrapped)                  // query user: db down
fmt.Println(errors.Is(wrapped, base)) // true
```

`%w` 只能用在 `fmt.Errorf` 中。它把原错误包进新错误，`errors.Is`/`errors.As` 可以沿链查找（第 08 章）。`%v` 只保留文本，丢失错误链。

### 12.1.7 `Scan` / `Scanln`（了解）

`fmt.Scanln(&name, &age)` 从标准输入读取，必须传指针，返回 `(n int, err error)`。实际业务中更常用 `bufio.Scanner` 或命令行参数，知道有这两个函数即可。

## 12.2 strings

`strings` 处理 UTF-8 字符串。字符串不可变，所有「修改」操作都返回新字符串。

### 12.2.1 包含、前后缀

```go
s := "  Hello, Go World  "

fmt.Println(strings.Contains(s, "Go"))                    // true
fmt.Println(strings.HasPrefix(strings.TrimSpace(s), "Hello")) // true
fmt.Println(strings.HasSuffix(strings.TrimSpace(s), "World")) // true
fmt.Println(strings.EqualFold("Go", "GO"))                // true
```

`Contains` 判断子串是否存在；`HasPrefix`/`HasSuffix` 判断前缀/后缀；`EqualFold` 忽略大小写比较。

### 12.2.2 拆分与连接

```go
parts := strings.Split("go,ts,js", ",")
fmt.Println(parts)                  // [go ts js]
fmt.Println(strings.Join(parts, " | ")) // go | ts | js
```

`Split` 返回 `[]string`；`Join` 把 `[]string` 用分隔符连接。`SplitN(s, sep, n)` 可以限制拆分段数。

### 12.2.3 去除空白与前后缀

```go
s := "  Hello, Go World  "

fmt.Printf("%q\n", strings.TrimSpace(s)) // "Hello, Go World"
fmt.Printf("%q\n", strings.Trim(s, " ")) // "Hello, Go World"
fmt.Println(strings.TrimPrefix("go-web", "go-")) // web
fmt.Println(strings.TrimSuffix("main.go", ".go")) // main
```

`TrimSpace` 去掉首尾所有空白；`Trim(s, cutset)` 去掉首尾**字符集合**中的字符，不是去掉整个子串；`TrimPrefix`/`TrimSuffix` 去掉指定的整个前缀/后缀。常见错误：想删 `"http://"` 却写成 `Trim(s, "http://")`，它会删掉所有 `h`、`t`、`p`、`:`、`/` 字符，应该用 `TrimPrefix`。

### 12.2.4 替换与切割

```go
fmt.Println(strings.Replace("a-b-c", "-", "_", 1))  // a_b-c
fmt.Println(strings.ReplaceAll("a-b-c", "-", "_"))  // a_b_c

before, after, found := strings.Cut("key=value", "=")
fmt.Println(before, after, found) // key value true
```

`Replace(s, old, new, n)` 替换前 n 个，`n < 0` 表示全部；`ReplaceAll` 全部替换；`Cut` 按第一个分隔符切成两段，返回 `(before, after, found)`，比 `SplitN` 更直观。

### 12.2.5 `Fields`：按空白拆分

```go
fmt.Println(strings.Fields("  go   is  fun ")) // [go is fun]
```

`Fields` 按一个或多个空白字符拆分，自动忽略首尾空白，适合处理命令行、日志行。

### 12.2.6 `Builder`：高效拼接

```go
var b strings.Builder
for i := 1; i <= 3; i++ {
    fmt.Fprintf(&b, "%d,", i)
}
fmt.Println(b.String()) // 1,2,3,
fmt.Println(b.Len())    // 6
```

`strings.Builder` 内部维护字节缓冲区，避免 `+=` 反复分配。零值可直接用；写入用 `WriteString`、`WriteByte`、`WriteRune` 或 `fmt.Fprintf`；`String()` 返回当前内容；不要复制已使用的 Builder；可以 `Grow(n)` 预分配。

### 12.2.7 与 `bytes` 的对应关系

`strings` 的 `Contains`、`Split`、`Join`、`TrimSpace` 在 `bytes` 中都有同名函数，`strings.Builder` 对应 `bytes.Buffer`。字符串操作返回 `string`，字节操作返回 `[]byte`；网络、文件、JSON 场景常需要 `[]byte`。

## 12.3 strconv

`strconv` 负责字符串与基本类型的转换。Go 没有隐式转换，字符串和数字之间必须显式转换。

### 12.3.1 `Atoi` 与 `Itoa`

```go
n, err := strconv.Atoi("42")
fmt.Println(n, err) // 42 <nil>

_, err = strconv.Atoi("4.2")
fmt.Println(err) // strconv.Atoi: parsing "4.2": invalid syntax

s := strconv.Itoa(42)
fmt.Println(s) // 42
```

`Atoi(s)` 等价于 `ParseInt(s, 10, 0)`，返回 `int`；`Itoa(n)` 等价于 `FormatInt(int64(n), 10)`；失败时返回 `0` 和错误，必须检查 `err`。

### 12.3.2 `ParseInt` / `ParseUint`

```go
i64, err := strconv.ParseInt("-123", 10, 64)
fmt.Println(i64, err) // -123 <nil>

u64, err := strconv.ParseUint("ff", 16, 64)
fmt.Println(u64, err) // 255 <nil>
```

参数依次是字符串、进制、位数。进制为 `0` 时根据前缀自动判断（`0x` 十六进制、`0b` 二进制、`0o` 八进制）；位数可取 0、8、16、32、64，限制结果范围。`ParseUint` 不接受负号，`"-1"` 会返回错误。

### 12.3.3 `ParseFloat` / `FormatFloat`

```go
f, err := strconv.ParseFloat("3.14", 64)
fmt.Println(f, err) // 3.14 <nil>

fmt.Println(strconv.FormatFloat(3.14159, 'f', 2, 64)) // 3.14
```

`FormatFloat(f, fmt, prec, bitSize)` 中，`fmt` 取 `'f'`（普通小数）、`'e'`（科学计数）、`'g'`（自动选择）；`prec` 是小数位数，`-1` 表示最短表示；`bitSize` 是 32 或 64。

### 12.3.4 进制转换与布尔

```go
fmt.Println(strconv.FormatInt(255, 16)) // ff
fmt.Println(strconv.FormatInt(255, 2))  // 11111111

b, err := strconv.ParseBool("true")
fmt.Println(b, err) // true <nil>

fmt.Println(strconv.Quote("go")) // "go"
fmt.Println(strconv.Unquote(`"go"`)) // go <nil>
```

`FormatInt` 的第二个参数是进制（2–36）。`ParseBool` 接受 `1`、`t`、`TRUE`、`true`、`0`、`f`、`FALSE`、`false` 等写法。

### 12.3.5 不要用 `string(n)` 转数字

```go
fmt.Println(string(65))          // A（按 Unicode 码点转字符）
fmt.Println(strconv.Itoa(65))    // 65（数字转十进制字符串）
```

这是第 02 章讲过的经典错误。整数转字符串用 `Itoa` 或 `FormatInt`。

## 12.4 bytes.Buffer

### 12.4.1 基本用法

```go
var buf bytes.Buffer

buf.WriteString("hello")
buf.WriteByte(' ')
buf.WriteString("go")
fmt.Println(buf.String()) // hello go
fmt.Println(buf.Len())    // 8

fmt.Fprintf(&buf, " %d", 2026)
fmt.Println(buf.String()) // hello go 2026

buf.Reset()
fmt.Println(buf.Len()) // 0
```

`bytes.Buffer` 的零值可以直接使用。`Write`/`WriteString`/`WriteByte` 写入；`String()` 转字符串；`Bytes()` 返回底层字节切片；`Len()` 当前长度；`Reset()` 清空复用；`Grow(n)` 预分配。`Bytes()` 与 Buffer 共享底层数组，Buffer 再写入可能影响它，需要长期保存时先 `Clone`。

### 12.4.2 实现 `io.Reader` / `io.Writer`

`*bytes.Buffer` 同时实现了 `io.Reader`、`io.Writer`、`io.ByteReader` 等接口，因此可以直接传给需要这些接口的函数：

```go
var buf bytes.Buffer
fmt.Fprintf(&buf, "value=%d", 42)
fmt.Print(buf.String()) // value=42
```

这是把「写文件/写网络」的代码改成「写内存」的常用测试技巧。

### 12.4.3 与 `strings.Builder` 的选择

只拼接字符串用 `strings.Builder`；需要读取、重置、当 `io.Writer` 或处理 `[]byte` 用 `bytes.Buffer`。两者都避免 `+=` 的反复分配，Builder 更轻，Buffer 功能更全。

## 12.5 sort

### 12.5.1 `sort.Slice`

```go
type User struct {
    Name string
    Age  int
}

users := []User{{"张三", 28}, {"李四", 22}, {"王五", 35}}
sort.Slice(users, func(i, j int) bool {
    return users[i].Age < users[j].Age
})
fmt.Println(users) // [{李四 22} {张三 28} {王五 35}]
```

`sort.Slice` 用反射访问切片，比较函数返回「i 是否应排在 j 前面」。它不要求元素实现接口，适合临时排序。

### 12.5.2 `sort.Sort` 与 `sort.Interface`

```go
type ByAge []User

func (a ByAge) Len() int           { return len(a) }
func (a ByAge) Less(i, j int) bool { return a[i].Age < a[j].Age }
func (a ByAge) Swap(i, j int)      { a[i], a[j] = a[j], a[i] }

sort.Sort(ByAge(users))
fmt.Println(users) // [{李四 22} {张三 28} {王五 35}]
```

`sort.Interface` 要求三个方法：`Len`、`Less`、`Swap`。命名切片类型实现接口后，可以复用排序逻辑，也可以配合 `sort.Reverse` 降序：

```go
sort.Sort(sort.Reverse(ByAge(users)))
fmt.Println(users) // [{王五 35} {张三 28} {李四 22}]
```

### 12.5.3 稳定性

稳定排序保证相等元素的相对顺序不变：

```go
users = []User{{"张三", 28}, {"李四", 22}, {"王五", 28}}
sort.SliceStable(users, func(i, j int) bool {
    return users[i].Age < users[j].Age
})
fmt.Println(users) // [{李四 22} {张三 28} {王五 28}]
```

`sort.SliceStable` 是稳定排序；`sort.Slice` 不保证稳定。需要「先按年龄，年龄相同保持原顺序」时用 Stable 版本。

### 12.5.4 查找

```go
nums := []int{5, 2, 9, 1}
sort.Ints(nums)
fmt.Println(nums) // [1 2 5 9]

idx := sort.SearchInts(nums, 9)
fmt.Println(idx) // 3
```

`sort.SearchInts` 要求切片**已排序**，返回第一个 `>= target` 的下标；找不到时返回插入位置（可能等于 `len(nums)`）。

### 12.5.5 和 `slices` 的关系

新代码优先用 `slices.Sort` / `slices.SortFunc`（12.6），它们类型更安全、性能通常更好。`sort` 仍然常见于旧代码和需要 `sort.Interface` 的场景。

## 12.6 slices

`slices` 从 Go 1.21 起提供，是操作切片的首选工具。

### 12.6.1 排序

```go
nums := []int{3, 1, 2}
slices.Sort(nums)
fmt.Println(nums) // [1 2 3]

users := []User{{"张三", 28}, {"李四", 22}}
slices.SortFunc(users, func(a, b User) int {
    return cmp.Compare(a.Age, b.Age)
})
fmt.Println(users) // [{李四 22} {张三 28}]
```

`slices.Sort` 要求元素满足 `cmp.Ordered`；`slices.SortFunc` 的比较函数返回负数/0/正数。两者都是原地排序，不返回新切片。

### 12.6.2 查找

```go
nums := []int{1, 2, 3, 4}

fmt.Println(slices.Contains(nums, 3)) // true
fmt.Println(slices.Index(nums, 3))    // 2
fmt.Println(slices.Index(nums, 9))    // -1

idx := slices.IndexFunc(nums, func(n int) bool { return n > 2 })
fmt.Println(idx) // 2
```

`Contains`/`Index` 要求元素 `comparable`；`IndexFunc` 接受任意条件。

### 12.6.3 插入与删除

```go
nums := []int{1, 2, 3}

nums = slices.Insert(nums, 1, 9)
fmt.Println(nums) // [1 9 2 3]

nums = slices.Delete(nums, 1, 2) // 删除 [1, 2)
fmt.Println(nums) // [1 2 3]
```

两者都可能修改底层数组，并**返回新的切片头**，必须接住返回值。`Delete(s, i, j)` 删除左闭右开区间，越界会 panic。

### 12.6.4 克隆、比较、反转、去重

```go
a := []int{1, 2, 3}
b := slices.Clone(a)
fmt.Println(slices.Equal(a, b)) // true

b[0] = 99
fmt.Println(a) // [1 2 3]
fmt.Println(b) // [99 2 3]

slices.Reverse(a)
fmt.Println(a) // [3 2 1]

dup := []int{1, 1, 2, 2, 3}
dup = slices.Compact(dup)
fmt.Println(dup) // [1 2 3]
```

- `Clone` 创建新底层数组，`Clone(nil)` 返回 `nil`；
- `Equal` 按元素比较，要求 `comparable`；
- `Reverse` 原地反转；
- `Compact` 去除**相邻**重复元素，通常先排序再 Compact。

## 12.7 maps

### 12.7.1 `Clone`、`Copy`、`Equal`

```go
m := map[string]int{"a": 1, "b": 2}

m2 := maps.Clone(m)
fmt.Println(maps.Equal(m, m2)) // true

m2["c"] = 3
fmt.Println(len(m), len(m2)) // 2 3

dst := map[string]int{"x": 100}
maps.Copy(dst, m)
fmt.Println(dst) // map[a:1 b:2 x:100]
```

- `Clone(nil)` 返回 `nil`；
- `Copy` 把 src 覆盖到 dst，保留 dst 原有的其他键；
- `Equal` 要求键和值都 `comparable`；
- 打印顺序由 `fmt` 排序，但**遍历顺序仍然随机**。

### 12.7.2 `DeleteFunc` 与 `EqualFunc`

```go
m := map[string]int{"a": 1, "b": 2, "c": 3}
maps.DeleteFunc(m, func(k string, v int) bool { return v < 2 })
fmt.Println(m) // map[b:2 c:3]

s1 := map[string][]int{"a": {1, 2}}
s2 := map[string][]int{"a": {1, 2}}
fmt.Println(maps.EqualFunc(s1, s2, func(a, b []int) bool {
    return slices.Equal(a, b)
})) // true
```

值是切片、map 等不可比较类型时，用 `EqualFunc`。

### 12.7.3 `Keys`、`Values` 与版本差异

Go 1.23 起，`maps.Keys`/`Values` 返回迭代器 `iter.Seq`，不是切片：

```go
m := map[string]int{"b": 2, "a": 1, "c": 3}

fmt.Println(slices.Sorted(maps.Keys(m)))   // [a b c]
fmt.Println(slices.Sorted(maps.Values(m))) // [1 2 3]
```

这段代码需要 Go 1.23+。Go 1.22 没有这两个函数，需要手写循环：

```go
keys := make([]string, 0, len(m))
for k := range m {
    keys = append(keys, k)
}
sort.Strings(keys)
fmt.Println(keys) // [a b c]
```

只需要遍历时，直接 `for k, v := range m` 最简单，也不受版本影响。

## 12.8 time

### 12.8.1 `Time` 与 `Duration`

- `time.Time`：时间点；
- `time.Duration`：时间段，底层是 `int64` 纳秒。

```go
d := 2*time.Hour + 30*time.Minute
fmt.Println(d)                // 2h30m0s
fmt.Println(d.Seconds())      // 9000
fmt.Println(d.Milliseconds()) // 9000000

d2, err := time.ParseDuration("1h30m")
fmt.Println(d2.Minutes(), err) // 90 <nil>
```

常用单位：`time.Nanosecond`、`Microsecond`、`Millisecond`、`Second`、`Minute`、`Hour`。`time.Duration(5)` 是 5 纳秒，不是 5 秒。

### 12.8.2 `Now` 与 `Date`

```go
now := time.Now()
fmt.Println(now.Year(), now.Month(), now.Day())

t := time.Date(2026, 10, 17, 12, 0, 0, 0, time.UTC)
fmt.Println(t) // 2026-10-17 12:00:00 +0000 UTC
```

`time.Date(year, month, day, hour, min, sec, nsec, loc)` 的 `month` 类型是 `time.Month`，可以传 `time.October` 或 `10`。

### 12.8.3 格式化：参考时间

Go 不使用 `YYYY-MM-DD` 这种占位符，而是用一个**固定的参考时间**：`2006-01-02 15:04:05`。记忆方法：`1 2 3 4 5 6` 对应月、日、时、分、秒、年。

```go
t := time.Date(2026, 10, 17, 12, 0, 0, 0, time.UTC)

fmt.Println(t.Format("2006-01-02 15:04:05")) // 2026-10-17 12:00:00
fmt.Println(t.Format(time.RFC3339))          // 2026-10-17T12:00:00Z
fmt.Println(t.Format("2006/01/02"))          // 2026/10/17
```

只要日期用 `2006-01-02`，只要时间用 `15:04:05`，带毫秒用 `2006-01-02 15:04:05.000`，RFC3339 用 `time.RFC3339`。

### 12.8.4 解析

```go
parsed, err := time.Parse("2006-01-02 15:04:05", "2026-10-17 12:00:00")
fmt.Println(parsed, err) // 2026-10-17 12:00:00 +0000 UTC <nil>

fmt.Println(parsed.Year(), parsed.Month(), parsed.Day()) // 2026 October 17
fmt.Println(parsed.Weekday()) // Saturday
```

要点：布局必须和参考时间一致，不是随便写的格式串；`time.Parse` 返回 **UTC** 时间；按指定时区解析用 `time.ParseInLocation(layout, value, loc)`；失败返回零值和错误，必须检查 `err`。

```go
loc, _ := time.LoadLocation("Asia/Shanghai")
t, err := time.ParseInLocation("2006-01-02 15:04:05", "2026-10-17 12:00:00", loc)
fmt.Println(t, err) // 2026-10-17 12:00:00 +0800 CST <nil>
```

### 12.8.5 `Unix` 与 `UnixMilli`

```go
t := time.Date(2026, 10, 17, 12, 0, 0, 0, time.UTC)
fmt.Println(t.Unix())      // 1792238400（秒）
fmt.Println(t.UnixMilli()) // 1792238400000（毫秒）

fmt.Println(time.Unix(0, 0).UTC()) // 1970-01-01 00:00:00 +0000 UTC
```

`Unix()` 返回秒，`UnixMilli()` 返回毫秒，`UnixNano()` 返回纳秒。数据库、JWT、日志常用 Unix 时间戳；注意别把秒和毫秒混用（乘以/除以 1000）。

### 12.8.6 UTC、Local 与时区

```go
cst := time.FixedZone("CST", 8*3600)
t := time.Date(2026, 10, 17, 12, 0, 0, 0, cst)

fmt.Println(t.Format("2006-01-02 15:04:05 -0700 MST")) // 2026-10-17 12:00:00 +0800 CST
fmt.Println(t.UTC().Format("2006-01-02 15:04:05"))     // 2026-10-17 04:00:00
```

`time.UTC` 是 UTC 时区；`time.Local` 是运行环境本地时区；`time.FixedZone(name, offsetSeconds)` 是固定偏移；`time.LoadLocation("Asia/Shanghai")` 按 IANA 时区名加载（需要时区数据库）。

服务器建议统一用 UTC 存储和传输，展示时再转本地时区。GORM 的 `time.Time` 字段要注意数据库连接串里的 `loc`/`time_zone` 配置。

### 12.8.7 时间运算与比较

```go
t := time.Date(2026, 10, 17, 12, 0, 0, 0, time.UTC)

fmt.Println(t.Add(48 * time.Hour).Format("2006-01-02 15:04:05")) // 2026-10-19 12:00:00
fmt.Println(t.AddDate(0, 1, 0).Format("2006-01-02"))             // 2026-11-17
fmt.Println(t.Sub(t.Add(-time.Hour)))                            // 1h0m0s

fmt.Println(t.Before(t.Add(time.Hour))) // true
fmt.Println(t.After(t.Add(-time.Hour))) // true
fmt.Println(t.Equal(t.UTC()))           // true
```

`Add` 加时间段；`AddDate` 加年/月/日；`Sub` 返回 `Duration`。比较用 `Before`、`After`、`Equal`，不要用 `==`：`==` 会比较单调时钟和时区信息，容易出错。

### 12.8.8 `Timer` 与 `Ticker`

`Timer` 一次性触发：

```go
timer := time.NewTimer(30 * time.Millisecond)
<-timer.C
fmt.Println("timer fired")
```

`Ticker` 周期性触发：

```go
ticker := time.NewTicker(10 * time.Millisecond)
defer ticker.Stop()

n := 0
for range ticker.C {
    n++
    fmt.Println("tick", n)
    if n == 3 {
        break
    }
}
```

输出为 `tick 1`、`tick 2`、`tick 3`。要点：`Ticker` 用完必须 `Stop`，否则泄漏；`time.After(d)` 是一次性 `Timer` 的简写；不要用 `Ticker` 做精确调度，它只保证「至少间隔」；热循环里避免反复 `time.After`。

### 12.8.9 常见坑

- 布局写成 `"YYYY-MM-DD"`：这些是普通字符，不是占位符，解析会失败；
- `time.Parse` 默认 UTC，展示成本地时间要 `In(time.Local)`；
- `t.Month()` 是 `time.Month` 类型，直接 `fmt.Println` 输出 `October`，要数字就 `int(t.Month())`；
- `time.Duration(5) * time.Second` 是 5 秒，`time.Duration(5)` 是 5 纳秒；
- 不要用 `==` 比较两个 `time.Time`；
- JSON 默认用 RFC3339 序列化 `time.Time`。

## 12.9 log/slog

### 12.9.1 为什么不用 `log`

标准库 `log` 只能输出纯文本，缺少级别和结构化字段。Go 1.21 引入 `log/slog`：支持 Debug/Info/Warn/Error 级别、键值对字段、Text/JSON 两种 Handler，适合生产。

### 12.9.2 基本用法

```go
logger := slog.New(slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
    Level: slog.LevelDebug,
}))

logger.Debug("cache miss", "key", "user:1")
logger.Info("user login", "user_id", 42, "ip", "127.0.0.1")
logger.Warn("slow query", "table", "users", "duration", "350ms")
logger.Error("db failed", "err", errors.New("connection refused"))
```

输出（时间随运行时刻变化）：

```
time=2026-10-17T12:00:00.000+08:00 level=DEBUG msg="cache miss" key=user:1
time=2026-10-17T12:00:00.000+08:00 level=INFO msg="user login" user_id=42 ip=127.0.0.1
time=2026-10-17T12:00:00.000+08:00 level=WARN msg="slow query" table=users duration=350ms
time=2026-10-17T12:00:00.000+08:00 level=ERROR msg="db failed" err="connection refused"
```

键值对必须成对出现，奇数个参数会得到 `!BADKEY`，例如 `logger.Info("bad", "key")` 输出 `... msg=bad !BADKEY=key`。

### 12.9.3 级别与 Handler

级别从低到高：`Debug`（-4，开发调试）、`Info`（0，正常业务）、`Warn`（4，可恢复异常）、`Error`（8，需要关注）。`HandlerOptions.Level` 设置最低输出级别；生产通常设为 `Info`，开发设为 `Debug`。`slog.Handler` 接口的核心方法是 `Enabled`、`Handle`、`WithAttrs`、`WithGroup`；一般直接用内置 Text/JSON Handler，不必自己实现。

```go
textLogger := slog.New(slog.NewTextHandler(os.Stdout, nil))
jsonLogger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

jsonLogger.Info("user login", "user_id", 42, "ok", true)
// {"time":"...","level":"INFO","msg":"user login","user_id":42,"ok":true}
```

JSON 适合被日志系统采集；Text 适合本地开发。

### 12.9.4 `With` 与 `WithGroup`

```go
reqLogger := logger.With("request_id", "req-123")
reqLogger.Info("handled", "status", 200)

grouped := logger.WithGroup("http")
grouped.Info("request", "method", "GET", "status", 200)
```

`With` 返回带固定字段的子   `WithGroup` 把字段放进命名组。Web 项目常用 `With` 绑定 TraceID、用户 ID。

### 12.9.5 最佳实践

用键值对，不要用 `fmt.Sprintf` 拼消息；错误字段统一用 `"err"`；不要记录密码、token、完整身份证号；一条日志只表达一个事件；请求入口生成 TraceID 往下传；生产用 JSON Handler。

```go
slog.SetDefault(logger)
slog.Info("server started", "addr", ":8080")
```

## 12.10 embed

`embed` 把文件打进二进制，部署时不需要额外带静态资源。

### 12.10.1 嵌入单个文件

目录结构：`demo/go.mod`、`demo/main.go`、`demo/assets/hello.txt`。`hello.txt` 内容为 `hello, embed`。

`main.go`：

```go
package main

import (
    _ "embed"
    "fmt"
)

//go:embed assets/hello.txt
var hello string

func main() {
    fmt.Print(hello) // hello, embed
}
```

要点：`//go:embed` 必须紧挨着变量声明，中间不能有空行；变量必须在包级，不能是局部变量；只嵌入字符串时，导入 `embed` 用空白导入 `_ "embed"`，否则「导入未使用」编译失败。嵌入 `[]byte` 同理：

```go
//go:embed assets/hello.txt
var helloBytes []byte
```

### 12.10.2 嵌入目录：`embed.FS`

```go
package main

import (
    "embed"
    "fmt"
)

//go:embed assets/templates/*.html
var templates embed.FS

func main() {
    data, err := templates.ReadFile("assets/templates/index.html")
    if err != nil {
        panic(err)
    }
    fmt.Print(string(data)) // <h1>Hello from embedded HTML</h1>

    entries, err := templates.ReadDir("assets/templates")
    if err != nil {
        panic(err)
    }
    for _, e := range entries {
        fmt.Println(e.Name(), e.IsDir()) // index.html false
    }
}
```

`embed.FS` 实现了 `fs.FS`，可以配合 `http.FileServer`、`template.ParseFS` 等使用。

### 12.10.3 规则

- 路径相对于**包含该 Go 文件的目录**，不能写 `../`，只能嵌入包目录内的文件；
- 默认忽略以 `.` 或 `_` 开头的文件；要包含用 `all:` 前缀，例如 `//go:embed all:assets`；
- 目录嵌入是递归的，空目录不会被嵌入；文件变化后必须重新编译；
- 多个 `//go:embed` 可以作用于同一个变量，路径用空格分隔。

### 12.10.4 与 Web 静态资源

```go
//go:embed assets/static
var staticFiles embed.FS

sub, _ := fs.Sub(staticFiles, "assets/static")
http.Handle("/static/", http.StripPrefix("/static/", http.FileServer(http.FS(sub))))

// Gin 中类似：r.StaticFS("/static", http.FS(sub))
```

这样静态文件被打进二进制，部署只需一个可执行文件。

## 12.11 常见错误与陷阱

| 错误/现象 | 原因 | 修复 |
|-----------|------|------|
| 时间解析失败 | 布局写成 `YYYY-MM-DD` | 用 `2006-01-02` |
| 时间差 8 小时 | `Parse` 返回 UTC | `ParseInLocation` 或 `.In(time.Local)` |
| `errors.Is` 失败 | 用了 `%v` 而不是 `%w` | `fmt.Errorf("...: %w", err)` |
| `%w` 在 `Printf` 中输出奇怪 | `%w` 只用于 `Errorf` | 改用 `%v` |
| `Atoi` 返回 0 却没报错 | 忽略了 `err` | 检查 `err` |
| `Trim` 删多了 | 第二个参数是字符集合 | 用 `TrimPrefix`/`TrimSuffix` |
| `Insert`/`Delete` 没变化 | 丢弃了返回值 | `s = slices.Insert(...)` |
| 排序结果不对 | 比较函数不是严格弱序 | 保证 `<` 语义一致 |
| map 遍历顺序每次不同 | Go 故意随机化 | 需要顺序先排序 key |
| `embed` 编译失败 | 指令和变量间有空行/路径越界 | 紧挨变量，路径在包内 |
| `embed` 文件没更新 | 没有重新编译 | 重新 `go build` |
| slog 出现 `!BADKEY` | 键值对数量为奇数 | 补全 key/value |
| 复制了 `bytes.Buffer` | 内部切片被复制 | 用指针传递 |
| `Ticker` 泄漏 | 忘记 `Stop` | `defer ticker.Stop()` |

### 12.11.1 排序比较函数必须一致

```go
sort.Slice(users, func(i, j int) bool {
    return users[i].Age <= users[j].Age // 错误：相等时也返回 true
})
```

比较函数应该表达严格的「小于」。使用 `<=` 可能让排序结果不稳定，甚至违反排序算法假设。正确写法是 `<`。

### 12.11.2 时区不是「字符串拼接」

```go
t, _ := time.Parse("2006-01-02 15:04:05", "2026-10-17 12:00:00")
fmt.Println(t) // 2026-10-17 12:00:00 +0000 UTC
```

如果业务期望北京时间，直接用 `time.Parse` 会得到 UTC。用 `ParseInLocation`，或者在展示时 `.In(loc)`。

### 12.11.3 `strings.Builder` 不要复制

```go
var b strings.Builder
b.WriteString("go")
b2 := b // 错误：复制了已使用的 Builder
```

Builder 内部有状态，复制后继续写可能 panic。需要传递时用指针 `*strings.Builder`。

## 12.12 与 Gin/GORM 的关联

### 12.12.1 参数处理

```go
id, err := strconv.ParseInt(c.Query("id"), 10, 64)
if err != nil {
    c.JSON(400, gin.H{"error": "invalid id"})
    return
}
```

`c.Query`、`c.Param` 都返回 `string`，转数字用 `strconv`。`ShouldBindQuery` 可以自动转换，但失败信息需要处理。

### 12.12.2 日志

Gin 的默认日志中间件输出请求行；业务日志建议用 `slog`：

```go
logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

func LoggerMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()
        c.Next()
        logger.Info("http request", "method", c.Request.Method,
            "path", c.Request.URL.Path, "status", c.Writer.Status(),
            "duration", time.Since(start))
    }
}
```

GORM 日志也分级（Silent/Error/Warn/Info），可以通过 `gorm.Config{Logger: ...}` 接入自定义 logger。

### 12.12.3 时间字段

```go
type User struct {
    ID        uint `gorm:"primaryKey"`
    CreatedAt time.Time
    UpdatedAt time.Time
    DeletedAt gorm.DeletedAt `gorm:"index"`
}
```

GORM 自动维护 `CreatedAt`、`UpdatedAt`。数据库连接串要配置时区（MySQL 的 `parseTime=true&loc=Local`）；API 返回 `time.Time` 时 JSON 默认用 RFC3339；比较时间用 `Equal`，不要用 `==`。

### 12.12.4 集合、配置与静态资源

查询结果排序/去重/查找用 `slices`；配置 map 复制/合并/比较用 `maps`；静态资源和模板用 `embed` + `http.FS`。

### 12.12.5 调试技巧

`fmt.Printf("%+v\n", user)` 看字段名和值，`%#v` 看完整类型，`%T` 确认接口背后的动态类型。排查 JSON 解码、GORM 查询结果时非常有用。
