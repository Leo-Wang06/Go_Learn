## 2.1 变量声明

### 2.1.1 四种声明方式

Go 声明变量有四种常见写法。

```go
package main

import "fmt"

func main() {
    // 方式一：完整声明
    var name string = "张三"

    // 方式二：类型推断
    var age = 25

    // 方式三：短变量声明（函数内最常用）
    score := 92.5

    // 方式四：先声明，后赋值
    var city string
    city = "北京"

    fmt.Println(name, age, score, city)
}
```

输出：

```
张三 25 92.5 北京
```

用 `%T` 查看推断出来的类型：

```go
fmt.Printf("%T %T %T %T\n", name, age, score, city)
```

输出：

```
string int float64 string
```

推断规则：

| 字面量 | 推断类型 |
|--------|----------|
| `25` | `int` |
| `92.5` | `float64` |
| `"张三"` | `string` |
| `true` | `bool` |
| `'中'` | `rune`（即 `int32`） |

---

### 2.1.2 `var` 与 `:=` 的区别

| 对比项 | `var` | `:=` |
|--------|-------|------|
| 使用位置 | 函数内、包级都可以 | **只能在函数内** |
| 是否必须赋值 | 可以不赋值（得到零值） | 必须赋值 |
| 是否写类型 | 可写可不写 | 不写，自动推断 |
| 能否重新声明 | 同名变量不能重复 `var` | 左侧至少要有一个新变量 |

示例：

```go
var a int       // 可以，a 是 0
var b = 1       // 可以，b 是 int
c := 2          // 可以，c 是 int
```

包级位置：

```go
package main

var global = "包级变量" // 正确

func main() {
    var local = "局部变量" // 正确
    // other := "不行"     // := 只能在函数内
}
```

如果在包级写 `:=`：

```go
package main

name := "张三" // 编译错误
```

错误类似：

```
syntax error: non-declaration statement outside function body
```

---

### 2.1.3 批量声明

```go
var (
    name string = "张三"
    age  int    = 25
    city string = "北京"
)
```

或者：

```go
var x, y int = 1, 2
```

在函数内也可以：

```go
a, b := 1, 2
```

---

### 2.1.4 多重赋值与交换变量

```go
a, b := 1, 2

a, b = b, a

fmt.Println(a, b)
```

输出：

```
2 1
```

Go 的多重赋值会先计算右侧所有值，再统一赋给左侧，所以交换不需要临时变量。

---

### 2.1.5 空白标识符 `_`

`_` 表示「我不关心这个值」。

```go
_, err := fmt.Println("hello")
if err != nil {
    fmt.Println(err)
}
```

`fmt.Println` 返回 `(n int, err error)`，这里用 `_` 忽略写入的字节数。

常见用途：

```go
for _, v := range []int{1, 2, 3} {
    fmt.Println(v)
}
```

只关心值，不关心索引。

---

### 2.1.6 短声明的三条规则

**规则一：左侧至少要有一个新变量。**

```go
a := 1
a := 2 // 编译错误：no new variables on left side of :=
```

正确写法：

```go
a = 2 // 已经声明过，用 =
```

**规则二：可以同时声明新变量和复用旧变量。**

```go
a, err := f()
b, err := g() // b 是新变量，err 复用，合法
```

**规则三：只在同一个作用域内复用。**

如果 `err` 在更外层，`:=` 会在当前块里创建一个新的 `err`，这就是「变量遮蔽」，见 2.7 节。

---

### 2.1.7 包级变量的初始化顺序

包级变量按依赖关系初始化。例如：

```go
var a = b + 1
var b = 2

func main() {
    fmt.Println(a) // 3
}
```

Go 会先初始化 `b`，再初始化 `a`。

包级变量允许声明后不使用；函数内的局部变量声明后必须使用，否则编译失败。

## 2.2 常量

### 2.2.1 `const` 基本用法

```go
const Pi = 3.14159
const Greeting string = "hello"

const (
    StatusOK       = 200
    StatusNotFound = 404
)
```

常量在编译期确定，不能被修改，也不能取地址：

```go
const C = 1
// C = 2      // 编译错误
// p := &C    // 编译错误：cannot take the address of C
```

---

### 2.2.2 常量必须是编译期可确定的值

允许：

```go
const (
    A = 1 + 2
    B = "hello" + " world"
    C = len("abc") // 字符串常量的长度，编译期可确定
)
```

不允许：

```go
import "time"

const Now = time.Now() // 编译错误：time.Now() 不是常量
```

---

### 2.2.3 无类型常量与有类型常量

**无类型常量**没有固定类型，会根据使用场景自动适配：

```go
const Answer = 42

var i int = Answer
var f float64 = Answer
var u uint = Answer

fmt.Println(i, f, u) // 42 42 42
```

**有类型常量**类型固定，赋值给其他类型需要显式转换：

```go
const Answer int = 42

var f float64 = Answer       // 编译错误
var g float64 = float64(Answer) // 正确
```

> 初学阶段建议：普通常量可以不写类型；做枚举或需要明确语义时，写上类型。

---

### 2.2.4 `iota`：常量计数器

`iota` 只能在 `const` 声明中使用，每遇到一行新的常量声明就加 1，从 0 开始。

```go
const (
    A = iota // 0
    B        // 1
    C        // 2
)
```

输出：

```go
fmt.Println(A, B, C) // 0 1 2
```

特点：

1. 每个 `const` 块开始时，`iota` 重置为 0；
2. 同一行有多个常量时，`iota` 只按行递增；
3. 如果某一行省略了表达式，会重复上一行的表达式（`iota` 仍按当前行取值）。

```go
const (
    X = iota // 0
    Y        // 1
)

const (
    Z = iota // 重新从 0 开始
)
```

---

### 2.2.5 用 `iota` 跳过值

用 `_` 占位：

```go
const (
    _  = iota             // 0，占位，不使用
    KB = 1 << (10 * iota) // iota = 1，1 << 10 = 1024
    MB                    // iota = 2，1 << 20 = 1048576
    GB                    // iota = 3，1 << 30 = 1073741824
)

func main() {
    fmt.Println(KB, MB, GB)
}
```

输出：

```
1024 1048576 1073741824
```

---

### 2.2.6 用 `iota` 定义枚举

```go
type OrderStatus int

const (
    OrderStatusPending OrderStatus = iota // 0
    OrderStatusPaid                       // 1
    OrderStatusShipped                    // 2
    OrderStatusCompleted                  // 3
    OrderStatusCancelled                  // 4
)
```

使用：

```go
func main() {
    var s OrderStatus = OrderStatusPaid
    fmt.Println(s)        // 1
    fmt.Printf("%T\n", s) // main.OrderStatus
}
```

> 现在打印出来是数字。第 05 章会学习给类型定义 `String()` 方法，让它打印成 `paid` 这样的可读文本。

---

### 2.2.7 用 `iota` 定义位标志

```go
type Permission uint

const (
    PermRead   Permission = 1 << iota // 1
    PermWrite                        // 2
    PermDelete                       // 4
)

func main() {
    p := PermRead | PermWrite

    fmt.Println(p)                 // 3
    fmt.Println(p&PermRead != 0)   // true
    fmt.Println(p&PermWrite != 0)  // true
    fmt.Println(p&PermDelete != 0) // false
}
```

位标志适合表示「可以同时拥有多个」的权限。

> 注意：`p&PermRead != 0` 会先计算 `p & PermRead`，再和 0 比较。`&` 的优先级高于 `!=`。

## 2.3 基本类型全景

### 2.3.1 布尔类型

```go
var ok bool = true
var no bool = false

fmt.Println(ok, no) // true false
```

Go 的 `bool` 不能和数字互转。下面这样写是错的：

```go
var b bool = 1 // 编译错误
```

TypeScript 里 `1` 可以当作真值，Go 不行。

---

### 2.3.2 整数类型

| 类型 | 范围 | 说明 |
|------|------|------|
| `int8` | -128 ~ 127 | 8 位有符号 |
| `int16` | -32768 ~ 32767 | 16 位有符号 |
| `int32` | -2147483648 ~ 2147483647 | 32 位有符号 |
| `int64` | -9223372036854775808 ~ 9223372036854775807 | 64 位有符号 |
| `int` | 平台相关 | 32 位或 64 位 |
| `uint8` | 0 ~ 255 | 8 位无符号 |
| `uint16` | 0 ~ 65535 | 16 位无符号 |
| `uint32` | 0 ~ 4294967295 | 32 位无符号 |
| `uint64` | 0 ~ 18446744073709551615 | 64 位无符号 |
| `uint` | 平台相关 | 32 位或 64 位 |
| `uintptr` | 平台相关 | 存指针的无符号整数，底层开发用 |

使用建议：

- 日常业务默认用 `int`；
- 数据库 ID、时间戳等需要明确宽度时用 `int64`；
- 明确不需要负数时用 `uint` 系列；
- `uintptr` 初学阶段不要碰。

查看当前平台的 `int` 是多少位：

```go
import "strconv"

fmt.Println(strconv.IntSize) // 32 或 64
```

---

### 2.3.3 浮点类型

```go
var f32 float32 = 3.14
var f64 float64 = 3.141592653589793

fmt.Println(f32, f64)
```

| 类型 | 精度 | 建议 |
|------|------|------|
| `float32` | 约 7 位十进制有效数字 | 对精度要求不高、节省内存时用 |
| `float64` | 约 15–17 位十进制有效数字 | **默认选择** |

浮点数的经典问题：

```go
fmt.Println(0.1 + 0.2)          // 0.30000000000000004
fmt.Println(0.1+0.2 == 0.3)     // false
```

不要直接用 `==` 比较两个计算出来的浮点数。需要比较时，用误差范围：

```go
func almostEqual(a, b, eps float64) bool {
    d := a - b
    if d < 0 {
        d = -d
    }
    return d < eps
}

fmt.Println(almostEqual(0.1+0.2, 0.3, 1e-9)) // true
```

> 金额不要用浮点数存储，数据库里用整数分或 `DECIMAL`。这一点在做订单系统时非常重要。

---

### 2.3.4 复数类型（了解）

```go
var c1 complex64 = complex(1, 2)
var c2 complex128 = complex(3.0, 4.0)

fmt.Println(c1, c2)         // (1+2i) (3+4i)
fmt.Println(real(c1), imag(c1)) // 1 2
```

业务开发几乎用不到，知道有这两个类型即可。

---

### 2.3.5 `byte` 与 `rune`

```go
var b byte = 'A'  // byte 是 uint8 的别名
var r rune = '中' // rune 是 int32 的别名

fmt.Println(b, r)           // 65 20013
fmt.Printf("%c %c\n", b, r) // A 中
```

区别：

| 类型 | 本质 | 用途 |
|------|------|------|
| `byte` | `uint8` 的别名 | 字节、二进制数据、`[]byte` |
| `rune` | `int32` 的别名 | Unicode 码点、单个字符 |

注意：`'A'` 是字符字面量（rune），`"A"` 是字符串字面量（string）。

---

### 2.3.6 字符串与 UTF-8

Go 的 `string` 是**不可变的字节序列**，通常按 UTF-8 编码存储。

```go
s := "中"

fmt.Println(len(s))           // 3，UTF-8 字节数
fmt.Println([]byte(s))        // [228 184 173]
fmt.Println(len([]rune(s)))   // 1，Unicode 字符数
fmt.Printf("%c\n", []rune(s)[0]) // 中
```

结论：

- `len(s)` 得到的是字节数，不是字符数；
- 遍历字符串推荐用 `for range`，它按 rune 遍历；
- 按索引 `s[i]` 取到的是 `byte`，不是完整字符。

## 2.4 零值

### 2.4.1 什么是零值

变量声明后如果没有赋值，Go 会自动把它初始化为该类型的零值。

```go
var i int
var f float64
var s string
var b bool
var p *int
var sl []int
var m map[string]int
var fn func()
var err error

fmt.Println(i)        // 0
fmt.Println(f)        // 0
fmt.Println(s)        // 空字符串
fmt.Println(b)        // false
fmt.Println(p)        // <nil>
fmt.Println(sl)       // []
fmt.Println(m)        // map[]
fmt.Println(fn)       // <nil>
fmt.Println(err)      // <nil>
```

### 2.4.2 零值对照表

| 类型 | 零值 |
|------|------|
| 所有整数类型 | `0` |
| 所有浮点类型 | `0` |
| `bool` | `false` |
| `string` | `""` |
| 指针 `*T` | `nil` |
| 切片 `[]T` | `nil` |
| map `map[K]V` | `nil` |
| channel `chan T` | `nil` |
| 函数 `func(...)` | `nil` |
| 接口 `interface{}` | `nil` |
| 结构体 `struct` | 每个字段各自的零值 |
| 数组 `[N]T` | 每个元素各自的零值 |

---

### 2.4.3 零值不是「未初始化」

TypeScript：

```ts
let name: string
console.log(name) // undefined
```

Go：

```go
var name string
fmt.Println(name) // 空字符串，不是 undefined
```

Go 没有 `undefined`。变量声明后一定有一个确定的值，这避免了「读到随机内存」的问题。

---

### 2.4.4 `nil` 的使用限制

`nil` 只能赋给这些类型：

- 指针；
- 切片；
- map；
- channel；
- 函数；
- 接口。

下面这样写是错的：

```go
var n int = nil     // 编译错误
var s string = nil  // 编译错误
var b bool = nil    // 编译错误
```

---

### 2.4.5 零值的可用性

不同零值的行为不一样，必须记住：

**nil 切片可以直接 append：**

```go
var s []int
s = append(s, 1, 2)
fmt.Println(s) // [1 2]
``` 

**nil map 可以读，但不能写：**

```go
var m map[string]int

fmt.Println(m["a"]) // 0，读不存在的 key 返回零值

m["a"] = 1 // panic: assignment to entry in nil map
```

必须先 `make`：

```go
m := make(map[string]int)
m["a"] = 1
```

**nil 指针解引用会 panic：**

```go
var p *int
fmt.Println(*p) // panic: runtime error: invalid memory address or nil pointer dereference
```

**nil 函数调用会 panic：**

```go
var f func()
f() // panic
```

**nil channel 的收发会永久阻塞：**

```go
var ch chan int
<-ch // 永久阻塞；如果程序中没有其他 goroutine，运行时会报 deadlock
```

> 这些行为在第 04、06、11 章会分别展开。现在先记住：**nil 不等于「安全空值」，不同类型行为不同。**

---

### 2.4.6 零值与 GORM 零值陷阱（重点）

```go
type User struct {
    ID   uint
    Name string
    Age  int
}
```

`Age int` 的零值是 `0`。GORM 无法仅凭结构体判断：

- 用户真的把年龄改成了 0？
- 还是用户根本没有设置年龄？

所以 GORM 在「用结构体更新」时，默认会忽略零值字段：

```go
// 想把年龄改成 0，但 GORM 可能忽略
db.Model(&User{ID: 1}).Updates(User{Age: 0})
```

解决办法：

```go
// 方式一：用 map，明确表达「我要更新 age」
db.Model(&User{ID: 1}).Updates(map[string]any{"age": 0})

// 方式二：用 Select 强制选中字段
db.Model(&User{ID: 1}).Select("age").Updates(User{Age: 0})
```

或者用指针字段区分「未设置」和「设置为 0」：

```go
type User struct {
    Age *int
}
```

- `Age == nil`：未设置，数据库存 `NULL`；
- `Age != nil` 且 `*Age == 0`：明确设置为 0。

> 这个坑会在第 06、18 章反复出现。现在只要理解：**零值是值，不是「没有值」**。

## 2.5 类型转换

### 2.5.1 基本语法

```go
T(v)
```

把 `v` 转换成类型 `T`。

```go
var i int = 42
var f float64 = float64(i)
var u uint = uint(i)
var i64 int64 = int64(i)

fmt.Println(f, u, i64) // 42 42 42
```

Go **没有隐式类型转换**。下面这样写是错的：

```go
var i int = 42
var f float64 = i // 编译错误
```

必须：

```go
var f float64 = float64(i)
```

---

### 2.5.2 数值转换：截断与溢出

**浮点转整数：向零截断。**

```go
fmt.Println(int(3.9))  // 3
fmt.Println(int(-3.9)) // -3
```

**整数转换：按目标类型截断。**

```go
n := 300
fmt.Println(int8(n)) // 44
```

为什么是 44？因为 `int8` 只有 8 位，300 对 256 取模得到 44。

> 重要区别：
> - 如果 `300` 是**常量**，`int8(300)` 在编译期就会报溢出错误；
> - 如果 `300` 是**变量**，转换在运行时截断，不会报错。

常量溢出示例：

```go
const Big = 300
var x int8 = Big // 编译错误：constant 300 overflows int8
```

运行时溢出示例：

```go
n := 300
fmt.Println(int8(n)) // 44，不会报错
```

**负数转无符号：按模运算。**

```go
var n int = -1
var u uint = uint(n)

fmt.Println(u) // 64 位平台：18446744073709551615
```

这种转换通常不是你想要的结果，业务代码里要避免。

---

### 2.5.3 整数溢出

整数运算溢出时，Go 会按二进制补码回绕：

```go
var x int8 = 127
x++
fmt.Println(x) // -128
```

```go
var y uint8 = 255
y++
fmt.Println(y) // 0
```

> 这类溢出不会 panic，也不会自动变成大数。做计数、金额、ID 计算时，要选择足够宽的类型。

---

### 2.5.4 字符串与数字：不要用 `string()` 转数字

这是初学者最容易犯的错误之一：

```go
fmt.Println(string(65))       // A
fmt.Println(strconv.Itoa(65)) // 65
```

原因：`string(65)` 把整数当作 Unicode 码点，65 对应字符 `'A'`。

正确做法：字符串和数字互转使用 `strconv`。

```go
import "strconv"

// 字符串 -> 整数
n, err := strconv.Atoi("123")
if err != nil {
    fmt.Println("转换失败：", err)
}
fmt.Println(n) // 123

// 整数 -> 字符串
s := strconv.Itoa(123)
fmt.Println(s) // "123"
```

其他常用函数：

```go
strconv.ParseInt("123", 10, 64)   // 指定进制和位数
strconv.ParseFloat("3.14", 64)    // 字符串 -> float64
strconv.FormatInt(123, 10)        // int64 -> 字符串
strconv.FormatFloat(3.14, 'f', 2, 64) // "3.14"
```

### 2.5.5 字符串与字节/字符切片

```go
s := "abc"

b := []byte(s)   // string -> []byte
fmt.Println(b)   // [97 98 99]

s2 := string(b)  // []byte -> string
fmt.Println(s2)  // abc

r := []rune("中文")
fmt.Println(r)        // [20013 25991]
fmt.Println(string(r)) // 中文
```

注意：

- `[]byte` 适合处理字节、二进制、网络数据；
- `[]rune` 适合按字符处理文本；
- 转换会产生新切片，有内存开销。

---

### 2.5.6 类型转换 vs 类型断言

| 写法 | 用途 | 适用场景 |
|------|------|----------|
| `T(v)` | 类型转换 | 数值、字符串、切片等兼容类型 |
| `v.(T)` | 类型断言 | 从接口中取出具体类型（第 07 章） |

```go
var x any = "hello"

s := x.(string) // 类型断言
fmt.Println(s)  // hello
```

现在只需要知道两者不是一回事，第 07 章会详细讲。

## 2.6 类型别名与新类型

### 2.6.1 两种写法

```go
type MyInt = int // 类型别名：MyInt 就是 int
type UserID int  // 新类型：UserID 和 int 是不同类型
```

区别：

| 写法 | 名称 | 和原类型的关系 |
|------|------|----------------|
| `type A = B` | 类型别名 | 完全相同，只是换了个名字 |
| `type A B` | 新类型 | 底层类型相同，但类型不同 |

---

### 2.6.2 别名：完全等价

```go
type MyInt = int

var a int = 1
var b MyInt = a // 正确，MyInt 就是 int

fmt.Println(b) // 1
```

标准库里的别名：

```go
type byte = uint8
type rune = int32
type any = interface{}
```

---

### 2.6.3 新类型：不能直接混用

```go
type UserID int
type OrderID int

var uid UserID = 1
var oid OrderID = 2

// uid = oid          // 编译错误：类型不同
uid = UserID(oid)     // 正确，显式转换
```

即使底层都是 `int`，Go 也不允许直接混用。这能防止「把用户 ID 当订单 ID」这类错误。

无类型常量可以直接赋值：

```go
var uid UserID = 1 // 正确，1 是无类型常量
```

---

### 2.6.4 新类型可以定义方法

```go
type UserID int

func (id UserID) String() string {
    return fmt.Sprintf("user-%d", int(id))
}

func main() {
    var id UserID = 42
    fmt.Println(id) // user-42
}
```

别名不能这样定义独立的方法，因为它就是原类型。

---

### 2.6.5 标准库中的新类型

| 类型 | 底层类型 | 用途 |
|------|----------|------|
| `time.Duration` | `int64` | 时间间隔，单位纳秒 |
| `time.Month` | `int` | 月份 |
| `os.FileMode` | `uint32` | 文件权限 |
| `json.Number` | `string` | 保留 JSON 数字的原始文本 |

示例：

```go
import "time"

var timeout time.Duration = 5 * time.Second
fmt.Println(timeout) // 5s
```

`time.Second` 本身是 `time.Duration` 常量，所以 `5 * time.Second` 得到 `time.Duration`。

---

### 2.6.6 什么时候用新类型

适合：

- 区分业务含义（`UserID`、`OrderID`）；
- 给值附加方法（`time.Duration.String()`）；
- 表达单位（秒、毫秒、字节）。

不适合：

- 只是为了换个短名字（用别名）；
- 过度包装，导致到处转换。

## 2.7 作用域与变量遮蔽

### 2.7.1 三种主要作用域

1. **包级作用域**：包内所有文件可见；
2. **函数级作用域**：函数内部可见；
3. **块级作用域**：`{}`、`if`、`for`、`switch` 内部可见。

```go
package main

import "fmt"

var global = "包级" // 整个包可见

func main() {
    fmt.Println(global)

    if true {
        local := "块级"
        fmt.Println(local)
    }

    // fmt.Println(local) // 编译错误：undefined: local
}
```

---

### 2.7.2 `if` / `for` / `switch` 中的变量

```go
if err := doSomething(); err != nil {
    fmt.Println(err)
}
// err 只在这里面可见
```

```go
for i := 0; i < 3; i++ {
    fmt.Println(i)
}
// i 在这里不可见
```

`if` 的初始化变量在 `else` 分支中仍然可见：

```go
if x := 10; x > 5 {
    fmt.Println("大于 5")
} else {
    fmt.Println(x) // 可以访问
}
```

---

### 2.7.3 变量遮蔽（shadowing）

在内层作用域用 `:=` 声明了与外层同名的变量，就会「遮蔽」外层变量。

```go
var err error

if true {
    err := fmt.Errorf("内部错误")
    fmt.Println("内部:", err)
}

fmt.Println("外部:", err)
```

输出：

```
内部: 内部错误
外部: <nil>
```

内层的 `err` 是一个新变量，外层的 `err` 没有被赋值。

---

### 2.7.4 最常见的遮蔽 bug：`err` 被吞掉

```go
func doSomething() error {
    var err error

    if true {
        result, err := f() // 注意：这里声明了新的 err
        _ = result
    }

    return err // 永远是 nil
}
```

你以为在检查 `f()` 的错误，实际上检查的是一个新变量。外层 `err` 一直是 `nil`。

修复方式一：使用 `=`，不要用 `:=`：

```go
var err error
var result int

if true {
    result, err = f()
    _ = result
}
return err
```

修复方式二：把逻辑拆到独立函数，提前返回：

```go
func doSomething() error {
    result, err := f()
    if err != nil {
        return err
    }
    _ = result
    return nil
}
```

> Go 的 `go vet` 默认不一定会提示所有遮蔽问题。最可靠的办法是：看到 `:=` 时，先确认左边是否有已存在的变量。

---

### 2.7.5 不要遮蔽预声明标识符

Go 有一些预声明标识符：`true`、`false`、`nil`、`int`、`len`、`cap`、`make`、`new` 等。

```go
len := 3 // 合法，但非常糟糕
```

这会让你在当前作用域内无法再使用内置的 `len` 函数。不要这样做。

---

## 2.8 命名规范

| 对象 | 规范 | 示例 |
|------|------|------|
| 变量 | 驼峰，短作用域用短名 | `i`、`n`、`userName` |
| 常量 | 驼峰或全大写单词组合 | `MaxRetries`、`DefaultTimeout` |
| 导出标识符 | 首字母大写 | `User`、`ParseConfig` |
| 非导出标识符 | 首字母小写 | `user`、`parseConfig` |
| 缩写 | 全大写或全小写，保持一致 | `userID`、`URL`、`HTTPClient` |
| 错误变量 | `Err` 前缀 | `ErrNotFound` |
| 类型 | 名词，驼峰 | `UserID`、`OrderStatus` |
| 接口 | 常以 `-er` 结尾 | `Reader`、`Writer` |

补充：

- 接收者名字要短且一致，例如 `func (u User) Name() string`，不要用 `this`、`self`；
- 包名小写、简短，避免下划线；
- 避免包名和类型名重复，例如 `user.User` 读起来啰嗦，可以用 `user.Profile`。

## 2.9 常量与枚举实战

### 2.9.1 订单状态

```go
type OrderStatus int

const (
    OrderStatusPending OrderStatus = iota
    OrderStatusPaid
    OrderStatusShipped
    OrderStatusCompleted
    OrderStatusCancelled
)

func main() {
    var status OrderStatus = OrderStatusPaid
    fmt.Println(status) // 1

    if status == OrderStatusPaid {
        fmt.Println("订单已支付")
    }
}
```

输出：

```
1
订单已支付
```

### 2.9.2 权限位标志

```go
type Permission uint

const (
    PermRead   Permission = 1 << iota // 1
    PermWrite                        // 2
    PermDelete                       // 4
    PermAdmin                        // 8
)

func hasPermission(p, target Permission) bool {
    return p&target != 0
}

func main() {
    p := PermRead | PermWrite

    fmt.Println(hasPermission(p, PermRead))   // true
    fmt.Println(hasPermission(p, PermDelete)) // false

    p |= PermDelete
    fmt.Println(hasPermission(p, PermDelete)) // true
}
```

位标志的优点：一个整数可以同时表示多个权限，节省存储，判断方便。

## 2.10 与 Gin/GORM 的关联

### 2.10.1 GORM 的零值陷阱

见 2.4.6。核心结论：

- 结构体字段的零值会被 GORM 当作「未设置」；
- 想更新零值，用 `map` 或 `Select`；
- 想区分「未设置」和「设置为零」，用指针字段。

---

### 2.10.2 GORM 的 ID 类型

`gorm.Model` 的定义大致是：

```go
type Model struct {
    ID        uint `gorm:"primarykey"`
    CreatedAt time.Time
    UpdatedAt time.Time
    DeletedAt DeletedAt `gorm:"index"`
}
```

`ID` 是 `uint`，在 MySQL 中通常映射为 `BIGINT UNSIGNED`。

如果你自己定义模型：

```go
type User struct {
    ID   int64
    Name string
}
```

也可以，但要保持整个项目一致。不要一会 `int`、一会 `int64`，否则到处都要转换。

---

### 2.10.3 Gin 的 `binding:"required"` 与零值

```go
type CreateUserReq struct {
    Name string `json:"name" binding:"required"`
    Age  int    `json:"age" binding:"required"`
}
```

问题：`Age` 是 `int`，如果客户端传 `0`，validator 会把 `0` 当作零值，认为「没有填」，从而校验失败。

如果 0 是合法值，应该：

- 去掉 `required`，改用业务校验；
- 或者把字段改成 `*int`，用 `nil` 表示「没传」。

```go
type CreateUserReq struct {
    Name string `json:"name" binding:"required"`
    Age  *int   `json:"age" binding:"required"`
}
```

> 这是零值概念在 Web 参数校验中的直接体现。

---

### 2.10.4 `time.Duration` 与超时配置

```go
var timeout time.Duration = 5 * time.Second

fmt.Println(timeout)       // 5s
fmt.Println(timeout.Seconds()) // 5
```

Gin/GORM/HTTP 客户端的超时配置通常都是 `time.Duration`：

```go
srv := &http.Server{
    Addr:         ":8080",
    ReadTimeout:  5 * time.Second,
    WriteTimeout: 10 * time.Second,
}
```

`5 * time.Second` 之所以能直接用，是因为 `time.Second` 是 `time.Duration` 类型的常量。

---

### 2.10.5 JSON 数字与 `float64`

如果把 JSON 解析到 `any`，数字默认会变成 `float64`：

```go
var v any
json.Unmarshal([]byte(`{"age": 18}`), &v)

m := v.(map[string]any)
fmt.Printf("%T\n", m["age"]) // float64
```

所以业务代码里尽量把 JSON 解析到具体结构体：

```go
type Req struct {
    Age int `json:"age"`
}
```

这样 `Age` 就是 `int`，不会变成 `float64`。

## 2.11 常见错误与陷阱

### 2.11.1 错误速查表

| 错误/现象 | 原因 | 修复 |
|-----------|------|------|
| `:=` 在包级报错 | 短声明只能在函数内 | 改用 `var` |
| `no new variables on left side of :=` | 左侧全是已存在变量 | 改用 `=` |
| `declared and not used` | 局部变量未使用 | 使用或删除 |
| 外层 `err` 永远是 nil | 内层 `:=` 遮蔽了 `err` | 用 `=` 或提前返回 |
| `cannot use x (type int) as int64` | 类型不同 | 显式转换 |
| `5 / 2` 得到 2 | 整数除法截断 | 用浮点或先转 `float64` |
| `int8` 溢出变成负数 | 二进制回绕 | 选择足够宽的类型 |
| `string(65)` 得到 `A` | 整数按 Unicode 码点转字符 | 用 `strconv.Itoa` |
| `0.1+0.2 != 0.3` | 浮点精度误差 | 用误差范围比较 |
| `nil` 赋给 `int` 报错 | `nil` 只能用于特定类型 | 用零值 `0` |
| `-1` 转 `uint` 得到巨大数 | 无符号回绕 | 避免负数转无符号 |
| `assignment to entry in nil map` | map 没有 `make` | 先 `make` |
| `invalid memory address or nil pointer dereference` | nil 指针解引用 | 使用前判空 |
| `constant 300 overflows int8` | 常量超出目标类型范围 | 换类型或改值 |
| `constant 1.5 truncated to integer` | 浮点常量赋给整数 | 改类型或取整 |
| `cannot take the address of C` | 常量不可取地址 | 用变量 |

---

### 2.11.2 整数除法

```go
fmt.Println(5 / 2)   // 2
fmt.Println(5 / 2.0) // 2.5
```

两个整数相除，结果还是整数，小数部分直接丢弃。

需要小数时：

```go
a, b := 5, 2
fmt.Println(float64(a) / float64(b)) // 2.5
```

---

### 2.11.3 除零

整数除零会在运行时 panic：

```go
a, b := 1, 0
fmt.Println(a / b) // panic: runtime error: integer divide by zero
```

浮点除零在变量场景下会得到 `+Inf`、`-Inf` 或 `NaN`：

```go
a, b := 1.0, 0.0
fmt.Println(a / b) // +Inf
```

业务代码里要显式判断除数是否为 0。

---

### 2.11.4 有类型常量不能直接赋给其他类型

```go
const Answer int = 42

var f float64 = Answer // 编译错误
```

修复：

```go
var f float64 = float64(Answer)
```

---

### 2.11.5 类型别名不能定义独立方法

```go
type MyInt = int

func (m MyInt) Double() int { // 编译错误
    return int(m) * 2
}
```

因为 `MyInt` 就是 `int`，不能给非本地类型 `int` 定义方法。需要方法时用新类型：

```go
type MyInt int

func (m MyInt) Double() int {
    return int(m) * 2
}
```

## 2.14 本章小结

| 概念 | 一句话解释 | 易错点 |
|------|------------|--------|
| `var` | 声明变量，可在包级/函数内 | 不赋值时得到零值 |
| `:=` | 短声明，只能在函数内 | 左侧至少一个新变量 |
| `=` | 给已声明变量赋值 | 不能用来声明 |
| 零值 | 变量声明后的默认值 | 不是「没有值」 |
| `nil` | 特定类型的空值 | 不能赋给 `int`/`string` |
| 类型转换 | `T(v)` | 无隐式转换，可能截断/溢出 |
| 别名 | `type A = B` | 与原类型完全相同 |
| 新类型 | `type A B` | 与原类型不同，可定义方法 |
| 作用域 | 变量可见的范围 | 内层 `:=` 会遮蔽外层 |
| `iota` | 常量计数器 | 每个 `const` 块重置 |
| 位标志 | `1 << iota` | 用 `&` 判断，用 `|` 组合 |
